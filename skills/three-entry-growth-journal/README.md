# 三笔成长日记 · Three-Entry Growth Journal

陪你轻量记录一天：发生了什么，有过哪些情绪起伏，以及有没有靠近自己想过的生活。

可以随口讲，也可以发零散文字或语音转写。只写一笔、今天很平静、目标还没想清楚，都可以开始。不要求每天打卡，也不给生活打分。

## 三笔分别记什么

| 三笔 | 记录内容 |
| --- | --- |
| 第一笔：今天发生了什么 | 几件事、一次见面或一个生活片段，先把事实留下来 |
| 第二笔：今天有没有比较大的情绪起伏 | 你自己描述的感受，以及当时发生的事；平静或不知道也可以 |
| 第三笔：有没有离目标近一点 | 对照你确认的目标或理想生活，看看当天有什么联系；允许没有进展或暂时看不出来 |

如果你还在摸索想过什么样的生活，可以先记今天，再慢慢聊清楚方向。需要补充信息时，每次只问一个必要问题，你也可以选择先不回答。

## 怎么开始

在支持 Skill 的工具中载入本目录，以 [SKILL.md](SKILL.md) 为入口。支持 `$技能名` 的工具可以使用 `$three-entry-growth-journal` 调用。

可以直接这样说：

> 用三笔成长日记陪我记一下今天。一次只问我一个问题。

已经有一段零散记录时：

> 帮我把下面这段话整理成今天的三笔成长日记。保留我的说话方式，不替我补写感受或结论。

今天只想简单留几件事时：

> 今天只写第一笔，记下发生了什么就好。

不支持 Skill 的对话工具，也可以将 `SKILL.md` 的正文作为本次对话的指令提供给 AI，再说出你的需求。实际可用的历史记录和文件能力，以当前工具为准。

## 记几次之后，可以一起回顾

你请求或同意后，可以在累积约 5 次新记录时，于下一次继续写日记的对话中做一次短回顾。次数和节奏都能调整，不要求连续记录。

回顾会从实际可读取的记录中，找出较早与较晚片段的具体差异，并联系你确认的方向。它会区分你的明确判断和 AI 的暂时观察，也允许得出“目前还看不出变化”。

可以这样提出：

> 记满五次后，我们一起看看有哪些变化。请引用具体片段，暂时的猜测单独说明。

这项回顾发生在你继续对话时，不会自动创建后台任务。旧记录不可读取时，需要你提供希望纳入的内容。

## 愿意时，整理成一本手记

经过你同意，可以把一段真实记录整理成私密、可翻阅的手记，默认考虑适合手机阅读的 PDF。能否生成 PDF 或可编辑版本，取决于当前工具的文件制作能力。

成册时，会把事件、你表达过的感受和确认过的想法融合成带日期的自然叙事。三笔用于日常对话收集信息；手记默认不展示提问栏目、评分和复盘表格。

视觉上采用柔和纸张、清楚的中文字体、少量手写旁注和涂鸦，留足阅读空间。只使用你同意放入的照片或素材；没有照片也能用排版整理，不生成冒充真实经历的图片或个人物件。

可以这样提出：

> 把我提供的这几篇日记整理成一本可以在手机上翻看的手记。保留我的语气，先给我一版整理稿。

整理时不覆盖原始记录，整理稿可以继续修改。只有你确认过的版本才会标为已确认；一篇记录也可以先做简短预览。

## 隐私与边界

- 只依据当前对话及你提供或明确允许使用的相关记录，不自动访问所有账户历史。
- 不代填情绪、动机、目标或成长结论，不做人格判断或心理诊断。
- 不把真实日记、私人照片或个人经历写入公开技能、示例或代码仓库。
- 不默认将日记保存到外部服务、公开页面或共享空间；外部保存与分享需要你指定目的地和范围。
- 不自动设提醒、每日打卡或后台监控，也不承诺永久记住所有记录。
- 这个目录提供的是对话方法；数据保存和访问能力取决于你使用的工具。
