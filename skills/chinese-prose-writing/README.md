# ChineseProseWriting · 汉语文笔写作

给 AI 的中文写作教练。它治两种病，都是 AI 最容易得的：

1. **翻译腔**——AI 写的中文读起来像英文机翻。语法全对，句子通顺，但读第二遍开始觉得「哪儿怪怪的」。
2. **文艺腔**——AI 为了显得有文采，堆形容词、堆四字格、写「月光晚风星辰」「岁月静好山河远阔」。不是错，是端起来了。

**这个技能的默认调门是现代中文，不是美文。** 参照阿城、王小波、史铁生、余华、李娟那一档——短句、常用字、动词准、具体不空泛。

## 适合谁用

- 你让 ChatGPT 写中文，出来的东西一股「翻译腔」「英文味」。
- 你觉得 AI 的稿子「太文绉绉」「太文艺」「形容词太多」「像中考满分作文」。
- 你要写散文、随笔、书评、评论、品牌文案，希望读起来像人写的。
- 你手里有一段 AI 稿或英译中的稿，想让它「更像中文」。
- 你要引古诗文名句，需要靠谱出处。

## 它做什么

### 一、祛病（治翻译腔）

六类病灶，每一类都给了搜索式、改法和真实对照：

| 病灶 | 长什么样 | 怎么改 |
| --- | --- | --- |
| 万能弱动词 | 「对这个问题进行深入的探讨」 | 深入探讨这个问题 |
| 被动泛滥 | 「他被升为营长」 | 他升为营长 |
| 的的不休 | 一句话三个「的」 | 定语挪后，或删 |
| 连词堆砌 | 然而、因此、此外、并且、以及 | 删一半，不通就断句 |
| 抽象名词 | 「用户留存率有显著提升」 | 回头再来的人变多了 |
| 前饰长定语 | 「一个长得像你兄弟的男人」 | 一个男人，长得像你兄弟 |

### 二、降调（治文艺腔）

这一节是 2.0 版新增的，也是最影响观感的一步。做法是**减法**：

- 删掉所有「为了好看而存在」的字——多余形容词、装饰性修饰、无效修辞、刻意金句。
- 查**降调表**：氤氲/缱绻/旖旎/阑珊、绯/绛/缃/缥、仿若/宛如、亦/皆/乃/矣/焉、岁月静好/山河远阔/人间清醒——一律删或换。
- 查**意象私有度**：月光、晚风、星辰、旧巷、山海这类公共意象，换成只有你写得出的物象。每篇至少一个。
- 查**情绪是不是模板**：写怀旧就怅惘、写成长就释然、写生活就岁月静好——是模板，重写。

一条分界线记住就够：**真诚大于华丽，质感大于修饰，自然大于雕琢，本真大于氛围。**

### 三、上韵

中文的节奏不在词上，在长短句的搭配上。技能里给了可操作的节律规则：长短句交替、四字格用量（千字三处封顶）、叠词配额（2–3 组）、平仄的入门用法、「的」字瘦身四招，以及最有效的免费工具——朗读测试。

### 四、提质

结构用「凤头·猪肚·豹尾」和「起承转合」两套中国文章学的骨架；技法收白描、列锦、通感、留白、情绪藏细节、小波折六种。范本分两层：**底盘**是汪曾祺、沈从文、张爱玲、朱自清、老舍、鲁迅（教你别写坏）；**调门**是阿城、王小波、史铁生、余华、李娟、刘亮程（教你别写假）。

## 怎么用

### 给 ChatGPT 用（最直接）

打开 `references/chatgpt-instructions.md`，里面有四段可以直接整段复制的成品指令：

- **完整版**——贴到 ChatGPT 项目的 Instructions，或自建 GPT 的 Instructions。
- **精简版**（约 1300 字）——贴到「设置 → 个性化 → 自定义指令」，长期生效。
- **一句话版**——懒得配置时，每次写作前贴这一句就有效。
- **改写指令**——手里已有 AI 稿时，单次对话直接发。
- **写作模板**——从零写一篇时用。

推荐组合：精简版放自定义指令长期兜底，写作时再补发一次写作模板。

### 给支持 Skill 的工具用

安装本技能后，直接提需求即可：

> 用 ChineseProseWriting 帮我改这篇文章，去掉翻译腔。
>
> 用 ChineseProseWriting 写一篇 1200 字的散文，主题是「成都的雨」。先跟我确认人设和调子。

### 单独跑自检脚本

```bash
python scripts/clinic.py 稿子.txt
python scripts/clinic.py 稿子.txt --json
```

输出每一处病灶的行号、命中片段和改法。报告按两类分栏：

- **翻译腔（结构病）**——弱动词、被动、的的不休、连词、超长句、套话……
- **文艺腔（调门病）**——文言虚字、古雅词、古雅颜色词、模板句、公共意象、形容词串……

末尾给一句诊断判语（哪种病更重、该看哪份文件），并附体检数据（平均句长、「的」密度、长短句是否单调）。

## 用之前知道这几件事

- **这不是「一键变文豪」。** 它给的是诊断标准和改写规则，最终判断仍要人来做。工具能让你稳定避开 AI 腔的下限，上限靠你自己读了多少书。
- **禁用词是概率规则，不是绝对禁令。** 「进行」在「进行曲」里没错，「的」在需要的时候该用，「月光」用得好也可以留。脚本命中不等于错，报告里已把「硬信号/软信号」分开，需人工判断。
- **往「雅」的方向走要克制。** 2.0 版把古雅颜色词、文言虚字、四字格、叠词、通感全部标成了「限用/默认不用」。如果你确实要写古典题材或文言调门，那是例外，但请自觉统一，不要半文半白。
- **名句出处请复核。** `literary-sources.md` 中的名句多为通行版本，部分来自聚合类文章的二手汇总，已在文末标注。正式发表、教学或商用前，请用[古诗文网](https://www.gushiwen.cn/)或纸质权威版本核对作者与篇名。
- **改稿只改表达。** 事实、数字、专有名词一个都不动。

## 依据

技能里的每一条规则都有出处：

**翻译腔一侧**
- 余光中《怎样改进英式中文？——论中文的常态与变态》，原载《明报月刊》1987 年 10 月号
- 王力《略论语言形式美》《诗词格律》
- 汪曾祺《小说笔谈》（原载《写作》1991 年第 4 期）及论语言系列

**文艺腔与现代调门一侧（2.0 新增）**
- 徐则臣论王小波的「书面口语」（北京青年报，2017-06-18）
- 阿城的短句美学与常用字原则（王彬彬《阿城小说的修辞艺术》；人民日报海外版 2016-07-28）
- 史铁生的白描与「删无可删」（作家网《以结构驭情，以技法入心》）
- 余华的「不用华丽形容词」（浙江师范大学余华研究中心）
- 网红文艺腔四病灶与减法原则（经典文学网「祛除网红文艺腔」讲次）
- 汪曾祺《文心》一脉与「好的语言，都不是奇里古怪的」

**结构与技法一侧**
- 元·乔吉「凤头·猪肚·豹尾」（载陶宗仪《南村辍耕录》）；清·刘熙载《艺概·经义概》「起承转合」
- 夏丏尊、叶圣陶《文心》（1933）

每份 reference 文件末尾都列有完整出处表，并标明哪些来源未取得发布日期。

**建议的上手顺序**：先读 `anti-translation-ese.md` 第二节的速查表（半页，立刻能用），再读 `modern-voice.md` 第五节的降调表（一页，决定你的稿子会不会端起来）。
