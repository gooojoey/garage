# 祛病：欧化中文诊断与改写

> 本文件的全部规则来自三处可查证的源头：余光中《怎样改进英式中文？——论中文的常态与变态》（原载《明报月刊》1987 年 10 月号）、王力《中国现代语法》（1940 年代）中对汉语欧化语法的系统讨论、以及汪曾祺论语言的系列文章。文末列出处。

---

## 一、先弄清病根

大模型写中文之所以「像机翻」，不是因为模型不会中文，而是因为它在**用英文的逻辑组织句子，再把词换成汉字**。三个结构性原因：

1. 高质量可训练中文语料远少于英文，模型写中文时底层仍跑英文句法。
2. 训练中的人工反馈偏好「结构工整、条理分明」，于是模型偏爱对仗并列、四平八稳——而好读的中文常常是不对称的。
3. 语感无法被模型量化，只能靠在下达指令时**明确列出禁用句式 + 改写规则**来补。

这一点有直接的现实佐证：余光中在《翻译乃大道·译者独憔悴》里就警告过，「初习创作的青年，对于那些生硬、拙劣，甚至不通的『翻译体』，往往没有抗拒的能力，濡染既久，自己的『创作』就会向这翻译体看齐」——现在的模型正是这样一个「濡染既久」的书写者。

**关键判断：欧化是句式问题，不是词义问题。先改结构，再换词。**

## 二、六大病灶速查表

| # | 病灶 | 典型症状 | 搜索式（正则可用） | 改法 |
| --- | --- | --- | --- | --- |
| 1 | 万能弱动词 | 「进行 + 抽象名词」吃掉实义动词 | `进行\|作出\|予以\|加以\|给予\|开展\|实施` | 还原实义动词 |
| 2 | 被动泛滥 | 该主动的地方用了「被/由/受到/得以」 | `被\|由\|受到\|得以\|为.{0,6}所` | 改主动；或换用获/遭/挨/受 |
| 3 | 的的不休 | 一句话里「的」≥ 3 个 | 统计 `的` 密度 | 定语改后饰或删除 |
| 4 | 连词堆砌 | 「然而因此此外并且以及从而进而」连用 | `然而\|因此\|此外\|并且\|以及\|同时\|而且\|从而\|进而` | 删，或断成两句 |
| 5 | 抽象名词化 | 「可能性/必要性/难度」作主语 | `性\|度\|化` 结尾词 + `的` | 换成具体名词或动作 |
| 6 | 前饰长定语 | 中心词前挂一长串「的」 | 名词前连续 2 个以上「的」 | 定语挪后，逗号隔开 |

辅助病灶：**副词「地」滥用**（`地` 跟在成语或动词后）、**见 when 就「当」**、**代词冗余**（它/其/该/此/上述/这些）、**「们」乱加**。

## 三、逐条详解与对照

### 1. 万能弱动词：把动词拆成「弱动词 + 抽象名词」

余光中把「作出」「进行」称为「恶势力之大，几乎要吃掉一半的正规动词」。原文举例及改法：

> 「本校的校友对社会作出了重大的贡献。」→「本校的校友对社会贡献很大。」
> 「我们对国际贸易的问题已经进行了详细的研究。」→「我们对国际贸易的问题已经详加研究。」
> 「心理学家在老鼠的身上进行试验。」→「心理学家用老鼠来做试验。」（或：用老鼠试验）
>
> ——出处：余光中《怎样改进英式中文？》，中国日报网英语点津转载（2015-09-01）

**口诀：见到「进行/作出/予以/加以/给予/开展/实施」先问一句——那个真动词呢？**

同理还有「作出食用苹果的行为」→「我吃苹果」（百度百科「英式中文」举的例）。

### 2. 被动泛滥

余光中指出中文被动语气的两个毛病：一是用生硬被动取代自然主动，二是千篇一律只用「被」字，却不晓得从「受难」到「遇害」、从「挨打」到「遭殃」、从「受人指点」到「为世所重」，可用的字还有很多。

原文对照（同上出处）：

| 生硬被动 | 还原为主动 |
| --- | --- |
| 我不会被你这句话吓倒。 | 你这句话吓不倒我。 |
| 他被怀疑偷东西。 | 他有偷东西的嫌疑。 |
| 他这意见不被人们接受。 | 他这意见大家都不接受。 |
| 他被升为营长。 | 他升为营长。 |
| 他不被准许入学。 | 他未获准入学。 |

补充：中文里大量被动其实是**隐性被动**，不用「被」——「糖都吃光了」「戏看完了」「稿写了一半」「钱已经用了」。

### 3.「的」的不休

余光中把这列为禁忌之一：「不可『的的』不休」。

**判断标准：一句话里出现三个以上「的」，或连续多个逗号分句读完分不清主语是谁，就该拆。**

改法有三：
- **删**：白色的鸭子 → 白鸭；新买的书 → 新书
- **换语序（后饰）**：一个长得像你兄弟的男人 → 一个男人，长得像你兄弟
- **换动词**：他的收入的减少改变了他的生活方式 → 他因收入减少而改变了生活方式

### 4. 连词堆砌

英文靠 and / but / therefore 缝合，中文不靠。余光中举过 man and wife、you and I、back and forth 的例子：中文只说「夫妻」「你我」「前后」就够了。

一句话里的「然而、因此、此外、并且、以及、同时、而且、从而、进而」，**大部分可以删掉而不失原意**；如果删了就断了逻辑，说明这里本来就该是两句话。

### 5. 抽象名词作主语 / 名词化

英文常见以抽象名词作主语（The decline in his income…），直译成「他的收入的减少」就太西化。中文多以具体名词或人作主语。

- 「这个方案的可行性比较高」→「这个方案能落地」
- 「用户留存率有显著提升」→「回头再来的人变多了」
- 「需要提升学习效率」→「得学得更快」

**术语换动作**是让文字落地的通用手法：把行业黑话翻译成一个能看见的画面。

### 6. 前饰长定语 → 改后饰

中文的自然习惯是「中心词 + 说明」，英文习惯是「说明 + 中心词」。长定语前置是翻译腔最典型的形状。

- ❌ 那件我祖母在她年轻时从上海带回来的旗袍
- ✅ 那件旗袍，我祖母年轻时从上海带回来的

### 辅助 1：副词「地」滥用

成语或动词作状语时不必加「地」。努力地学习 → 努力学习；成功地完成 → 完成；极大地提高了 → 提高了。

### 辅助 2：代词冗余

中文少用代词，英文非用不可。它 / 其 / 该 / 此 / 上述 / 这些 出现时，多数情况下**换成具体名词反而更好读**。

余光中举例：有些学者名嘴会说「他自己不自知」「唯一的一次」，其实中文只要说「不自知」「只一次」就行了。

### 辅助 3：「们」不要乱加

中文的复数靠语境。「工人们、学生们、老师们」连排，是翻译散文体的显著标志。

### 辅助 4：见 when 就「当」

「当我走进房间的时候，我看见他」→「我走进房间，看见他」。中文的时间关系常靠语序，不必句句「当…的时候」。

## 四、余光中「铁不」禁忌（可直接抄进系统指令）

| 禁忌 | 说明 |
| --- | --- |
| 不可「见 when 就『当』」 | 语序自身能表时间 |
| 不可「见 if 就『如果』」 | 「要是」「若」「果真」 |
| 不可「突然 + 地」 | 「忽然」即可 |
| 不可「『被』挨打、『被』听见」 | 换用承受义动词 |
| 不可「『的的』不休」 | 一句话三个「的」即超载 |
| 不必「『关于』这件事」 | 直接说「这件事」 |
| 不必「『作出』贡献、『进行』讨论、『作为』……」 | 还原实义动词 |
| 各种代名词如 it 之类，可不译 | 视语境省略 |

> 这几条「铁不」，据澎湃新闻《余光中：翻译乃大道・译者独憔悴》一文整理，原文见该文中对余先生所条列「禁忌」的归纳。（澎湃新闻，URL 见文末）

**一个经典手术示例**（同源）：

- 原文：我被家人告诉我的朋友所出版的关于艺术的新的书已经被贩卖了。
- 手术后：家人告诉我朋友出版的艺术新书已上市。

一扫扫掉十一个废字。

## 五、定稿自检清单（改完必须逐条过）

- [ ] 全文搜 `进行|作出|予以|加以|给予|开展|实施`，逐个问「真动词呢」？
- [ ] 全文搜 `被`，逐个问「能不能改主动」？
- [ ] 找出一句话里「的」≥ 3 的地方，拆或删。
- [ ] 全文搜 `然而|因此|此外|并且|以及|同时|而且|从而|进而`，删掉一半。
- [ ] 找出所有超过 45 字无句号的长句，逐个断。
- [ ] 抽象名词作主语的句子，换成具体名词或动作。
- [ ] 代词 `它|其|该|此|上述|这些` 指代不清处换具体名词。
- [ ] 成语后多余的「地」全部删掉。
- [ ] 出声朗读一遍，结巴处即改。
- [ ] 事实、数字、专有名词：**一个没动**。
