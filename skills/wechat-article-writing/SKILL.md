# 微信公众号推文写作技能

## Overview

把近 30 天（2026.8–9）微信全平台高阅读量文章拆解成可复用的「标题公式 + 正文骨架 + 写作流程」，
让任何主题的推文都能稳定产出高打开率、高转发率的版本。所有结论均来自真实爆款样本，而非空泛理论。

## When to use

- 用户要写公众号文章 / 微信推文 / 新媒体文案，或要求「起一个爆款标题」「拆解爆文」。
- 用户要做选题、涨粉内容、热点跟进、本地/民生/政务/品牌号推文。
- 用户拿到一篇文章想优化标题或结构以拿到更高阅读量。

## 核心方法（三步）

### 1. 选题与角度
- 选题 = 80% 人群的普遍痛点 + 差异化表达；或蹭热点（尽快出稿吃第一波搜索流量，但须加一层深度分析才有收藏价值）。
- 从 `references/title_patterns.md` 的 8 种标题模式中选 1–2 个匹配角度。

### 2. 标题（占 80% 打开率）
- 加载 `references/title_patterns.md`：内含 **8 种标题模式**（数字痛点 / 反差反常识 / 悬念留白 / 热点权威 / 情绪共鸣 / 短句口语 / 民生警示 / 公告促销），每种带填空模板与真实样本；另附 **王炸词清单** 与 **标题禁忌**（敏感词、标题党红线）。
- 可用 `scripts/generate_titles.py` 批量生成候选：
  `python scripts/generate_titles.py --topic "脱发" --pain "发际线焦虑"`
  加 `--examples` 看真实爆款样例，加 `--check "标题"` 做禁忌词自检。
- 产出 5–10 个候选，按「读起来像朋友说的话吗 / 有没有代入感 / 踩没踩敏感词」筛选。

### 3. 正文结构
- 加载 `references/article_structures.md`：含 **SCQA 开头**（及其 ASC/CSQA/QSCA 变体）、**黄金三段式 / 金字塔 / 正反对比 / 故事串联 / 清单体** 五种骨架、**结尾推一把三件套**（金句+行动指令+福利钩子），以及 2026 新趋势（活人感、短节奏、价值前置、强情绪真细节、金句密度每300字1句）。
- 工作流：选题 → 定角度 → 出标题(5–10) → 搭骨架(SCQA开头+三段正文+结尾三件套) → 填血肉(真细节/口语/金句) → 自检。

## 写作风格红线
- 标题 2 秒看不懂就改；内容必须兑现标题承诺（否则取关率极高）。
- 避开敏感词：暴富、内幕、震惊、曝光、绝密 等易降权。
- 人定框架与观点，AI 填充论据与案例，头尾人工润色去 AI 味。
