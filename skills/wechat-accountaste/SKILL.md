# WeChatAccountaste

为已有文章建立清楚的阅读顺序、统一的视觉层级和有依据的图文节奏。根据文稿选择一种主导风格，保留内容本身的特点；不要把不同参考账号的外观拼成模板。

面向使用者的介绍与示例见 [README.md](README.md)。设计方法主要来自2015—2017年的案例，包含少量2019年补充；具体来源及验证边界见 [references/source-notes.md](references/source-notes.md)，仅在追溯依据或需要复刻具体样本时读取。

## 工作方式

1. 确定文章给谁看、读者应记住什么、文章类型及已有品牌约定。信息足够就开始，缺少可选素材不阻塞排版。
2. 使用用户最新稿件。辨认标题、导语、章节、正文、引文、问答、图片、图注、来源和行动提示；没有文案编辑授权时保留原文，只调整样式及合理分段。
3. 阅读 [references/aesthetic-system.md](references/aesthetic-system.md)，选择一种主导模式。先确定版心、层级和图文节奏，再做局部设计。固定品牌约定优先于默认数值。
4. 生成或修改 HTML 时阅读 [references/wechat-compatibility.md](references/wechat-compatibility.md)。用简单可编辑结构实现审美；先解决信息缺失、溢出和编辑兼容，再检查风格。
5. 对照原稿检查内容完整性，检查不同屏宽及可用的微信预览，按真实完成的检查报告状态。审查任务给出具体位置、问题及改法；实施任务直接修复范围内问题。

默认正文以14px为主，列表、导语和普通引文沿用14px；标题按层级适度放大，图注与来源保持清晰可读。这里的“14号”按公众号编辑器的14px处理。用户另有要求时调整。

## 必须保留的审美判断

- **读者先遇见内容。** 开头的图片、导语或问题须帮助进入文章；不要让关注提示、巨大刊头和装饰占满首屏。
- **层级有区别，同类有规律。** 读者能区分章节、正文、图注和署名；同类元素复用同一规则，不同章节不临时换模板。
- **节奏服务语义。** 章节留白大于段间留白，图注靠近图片；不机械规定每几段必须插图，不为“文艺”把每句话拆成一行。
- **图片承担任务。** 用人物、场景、物件、过程或细节推进叙述；连续图须有顺序，素材不足时接受纯文字。
- **辨识度来自持续选择。** 栏目名、序号、提问格式或单一强调色可成为稳定特征；日期、期号、作者身份须真实，不能伪造连载历史。
- **允许鲜明，但要有理由。** 生活方式稿可以安静，创意稿可以大胆。色块、插画和大字须共同表达一个概念；不是所有好排版都黑白极简。
- **设计不能损伤内容。** 不删事实限定、不伪造引语和来源、不把正文图片化；不使用读不清的小字换取“精致”。

## 选择主导模式

| 模式 | 适用内容 | 核心形式 |
| --- | --- | --- |
| 文艺阅读 | 随笔、阅读、情感、文化观点 | 连贯正文、少量引文、安静章节、有限插画 |
| 视觉杂志 | 人物、空间、器物、生活方式 | 大图与正文交替、真实图注、照片叙事 |
| 清晰行动 | 方法、成长、知识、活动说明 | 清楚编号、步骤或问答、重点可扫描 |
| 创意主题 | 品牌专题、节日概念、短篇创意 | 一个视觉概念统领，允许大字或色块 |

采访可使用问答组件，商品介绍可使用规格组件；它们服从整篇的主导模式，不各自发展一套风格。普通文稿没有明显类型时，选择连贯阅读的基础模式。

## 输出要求

实施通常交付正文 HTML、简短设计说明及未完成验证/素材缺口。已有项目约定其他格式时遵循约定。

- 只管排版：不改写、增删、补充或核查正文，不自动添加标题、摘要、金句、引用文章内容或推广语。原稿已有的引用、来源和链接不得自行删除；用户明确要求移出时才处理，其余正文保持原样。
- HTML 保留可编辑文字及真实 img，不混入工具说明、检查报告、调试字段或待办提示。
- 缺少关键图片时可在独立预览中标明待补，正式正文不放无效图片链接；缺口单列。
- 标题/摘要在公众号字段中处理，不默认在正文重复大标题。
- 只说实际完成的状态：生成文件、结构校验、浏览器预览、微信实机、草稿保存、发布彼此分开。
- 用户要求上传或发布时按已有授权推进；Skill 本身不授予跨账号发布、添加推广或改变仓库权限的授权。

## 完成前检查

逐项判断，而非只给一个主观“高级感”分数：

- 开头能自然进入内容，主信息没有被装饰压住。
- 层级清楚，同类元素统一，留白按语义分组。
- 插图与段落关联成立，图注/署名可读，图片不拉伸。
- 最窄测试宽度下标题自然换行，正文无横向溢出或叠字。
- 放大字号、深色模式以及编辑器再编辑的风险已经检查或明确标注待验证。
- 正文事实、数字、引语、链接、图片归属及必要条件完整。

如果装饰拿掉后信息更清晰，就先拿掉；如果文章失去了自身性格，检查是否过度删掉了有内容意义的栏目、影像或节奏。
