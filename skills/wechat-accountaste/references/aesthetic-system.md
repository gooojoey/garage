# 审美系统与排版决策

这些是综合设计建议，不是参考账号的官方参数。目标是“内容有气质、阅读有秩序、视觉有主见”。

## 1. 共用底层与可变表达

共用底层：稳定版心、可读文字、清楚层级、相关图片、明确归属、可靠编辑结构。

可变表达：正文对齐方式、强调色、章节符号、影像密度、局部色块、栏目仪式。每篇选择一种主导模式，通常只需一个能记住的特征。已有品牌成熟规范时沿用，而非重新设计。

参考账号的角色是一组不同能力：一条的影像导向；ONE与阿司匹林的读者语气和章节节奏；单向街的连续阅读；城市画报的人物及专题组织；良仓的器物叙事；LOHAS的场景与图注；行动派的稳定栏目；插坐学院的信息秩序；杜蕾斯的概念与形式呼应。具体历史证据有强弱区别，见source-notes.md，不把这些概括当成每篇文章的共同样式。

## 2. 基础参数

下列px均为CSS像素，行高为无单位倍数。默认值是一套能直接开始工作的选择，不为细微偏离报警。

| 元素 | 起点 | 可调整的理由 |
| --- | --- | --- |
| 正文与列表 | 14px，line-height:1.8，#333333 | 默认以14px为主；明确的大字阅读需求可调至16—17px，用户已有字号要求时优先 |
| 字体 | 不写font-family | 继承平台字体；不用宋体、英文字体栈模拟文学气质 |
| 字距 | 0 | 特定短标题可0.5—1px；长文不默认扩大字距 |
| 版心 | 单栏、width:100%、box-sizing:border-box | 适配宿主正文容器，不固定为手机像素宽 |
| 正文左右内边距 | 每侧16px，仅一层 | 宿主已提供较大留白则减少；避免窄屏只剩十余字一行 |
| 段间 | 20px | 紧凑问答16px；短诗按原稿节奏 |
| 一级章节 | 20px/1.5、加粗；上36px，下20px | 短文无需强行分章；长标题自然换行 |
| 二级标题 | 17px/1.6、加粗；上24px，下12px | 只有真实层级存在时使用 |
| 导语 | 14px/1.8，#555555 | 不以12px小字容纳长导语 |
| 引文 | 14px/1.8，#555555；上下24px | 重要内容不靠低对比度弱化；出处另行 |
| 图注 | 13px/1.6，#666666；图后8px | 很长时左对齐；不挤入照片边缘 |
| 图片组 | 上下24px；组内8px | 图注算组内，避免外边距重复累加 |
| 署名/来源 | 13px/1.7，#666666 | 信息完整、层级次于正文；不强制居中 |

正文不首行缩进。一般左对齐；长中文文稿若品牌惯用两端对齐，可在窄屏与混排检查后使用justify，单词间出现大空隙则回退left。不要把“两端对齐”写成所有文章的美学义务。

颜色从内容与品牌出发：基础黑灰；可选墨绿#365D4B、深蓝#315A74或暗红#B33A32之一。它们是本系统备选值，不归属于参考账号。大面积亮黄等高饱和颜色仅用于有明确概念的模块；文字与背景必须能读清。

## 3. 四种主导模式

### A. 文艺阅读

参考方向：ONE·文艺生活、阿司匹林博物馆、单向街书店。

- 正文形成连贯阅读流，不把每个段落装进卡片。允许一整段自然发展，不机械限制句数。
- 开篇可为一幅插画、一个有归属的引文或短导语；有真实连载信息才展示日期/期号。
- 章节用简单文字或编号即可，留白体现转换。引文独立但不夸张放大引号。
- 居中适合短诗、短题记和章节标题。长叙述、长引文、含URL的混排使用左对齐。
- 每张插图负责情绪或语义转场；无合适图片可纯文字。封面、插画和正文不能互相抢夺注意。

### B. 视觉杂志

参考方向：一条、城市画报-浮城会、良仓、LOHAS。

- 图片顺序先建立场景，再呈现人物/物件，再看细节；不只是按文件名排序。
- 章节是新的观看角度，不是随机出现的编号。人物简介、采访问答、器物说明属于不同信息层级。
- 普通照片无默认阴影、圆角和边框。保留原图比例；有意裁切必须保护脸、手、作品主体与图片文字。
- 图注说明“是谁、是什么、何处或来源”，不重复正文空泛评价。资料图片、剧照、实拍和AI图分别标识。
- 大图宽于正文文字块可以建立节奏；小尺寸原图居中限宽，避免强行放大。
- 商品稿先给出设计、使用情境和具体信息；规格/价格单独整理，不把每个卖点都标红。事实与功效原文若需核查，单列风险，不替其作背书。

### C. 清晰行动

参考方向：行动派DreamList、插坐学院。

- 让读者能扫描到问题、步骤及结论。章节编号连续且有意义。
- 一套稳定的栏目样式即可；可采用短标签或真实日期，不虚构陪伴天数和连载次数。
- 短步骤用列表，完整论述用段落；方法不能被排成零散口号。
- 重点优先加粗，每段通常突出一个意群；超过正文约10%时审查是否失去主次，不自动删用户强调。
- 活动时间、地点、费用、报名方式等字段清晰可找。可采用简单单栏信息块，不能为了简洁隐藏条件。

### D. 创意主题

参考方向：杜蕾斯的栏目化问答及创意一致性。

- 先用一句话说清视觉概念，所有颜色、图形和节奏都围绕它。没有概念就回归基础排版。
- 可以大字、纯色块、插画、短问答；大胆不等于每段不同颜色、不同边框。
- 全文只有一个主视觉语言；正文仍是可编辑文字。图形隐喻通过真实图片或简单结构表达。
- 不自动模仿成人双关、挑衅语气或品牌口号；参考的是设计方法，语气取决于当前用户品牌。
- 普通排版不依赖SVG互动。确实需要互动时单独设计并验证静态可读版本，避免内容必须点击才能看到。

## 4. 组件取舍

| 组件 | 何时有效 | 何时删除或降级 |
| --- | --- | --- |
| 栏目头 | 长期栏目已有名称 | 只有泛泛英文或无信息装饰时 |
| 日期/期号 | 真实连载、活动或档案需要 | 无真实记录，或占据大半首屏时 |
| 引文 | 有出处、改变阅读节奏 | 从正文随便摘一句充当金句时 |
| 细线/黑框 | 分隔明确层级 | 每个段落都有、与色块重复时 |
| 色块 | 汇总、问答或专题概念 | 仅为填满白底、深色难读时 |
| 图组 | 展示过程、空间或同一物件多个面 | 只有相似照片但无新增信息时 |
| 问答 | 原稿有采访或真实问题 | 虚构对话、为分块强行改写时 |
| 文末行动 | 用户任务需要或原稿已有 | 自动添加关注、购买或转发时 |

## 5. 具体修正例

- 原稿有三段人物故事和一幅肖像：用故事正文与肖像建立段落节奏，不生成“人物介绍/故事启示/总结提升”三个空泛卡片。
- 原稿是长篇书评：保留论述长度与引文，不把每句话居中；无需每屏一张图片。
- 原稿是六步操作：编号与步骤名清楚、相关截图紧随其后；缺图不插无关风景。
- 原稿是新品器物：场景图—设计细节—规格条件；不用廉价促销标签覆盖产品。
- 原稿是已有品牌创意：延续核心图形与主题色，不因默认黑灰把创意全部抹平。

这些是决策例，不是必须套用的文章结构。所有新生成的标题、摘要、引文改写须与纯排版任务分开处理。
