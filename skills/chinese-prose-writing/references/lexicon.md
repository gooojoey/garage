# 词库：让文字有质感的具体词

> 中文的质感来自**具体**：一个准的动词胜过三个华丽的形容词。本文件是可随手查的词表，不是必背清单。
> **使用纪律：一篇千字文，从本表里取用 5–8 处即可。堆砌词表是另一种 AI 腔。**
> **⚠️ 本表的默认调门是现代中文。第五节的古雅颜色词已改为「默认不用」，第六节之后另有高风险词黑名单。想要更雅的方向请先读 `modern-voice.md`——那里讲的是怎么把文章往下降调，而不是往上抬。**

---

## 一、动词：中文的原力

中文是动词的语言，英文是名词的语言。**动词准了，全句立住。**

### 表示「看」（单字比双字更有力）

瞥 · 瞅 · 瞄 · 瞪 · 盯 · 瞟 · 瞧 · 睹 · 望 · 窥

双字（按需要选）：凝视 · 注视 · 扫视 · 环视 · 俯视 · 窥视 · 巡视 · 远望 · 眺望 · 瞭望 · 张望 · 探望 · 仰望 · 观察 · 瞻仰 · 鸟瞰 · 视察 · 欣赏 · 观赏 · 浏览

> 用法：「看」是全能的，所以是弱的。「他看了一眼」不如「他瞟了一眼」或「他盯了一会儿」。

### 表示「说 / 叫 / 喊」

说：讲 · 曰 · 叫 · 喊 · 嚷 · 谈 · 问 · 议 · 诉 · 骂 · 讨论 · 议论 · 交谈 · 诉说 · 倾诉 · 告诉 · 叫嚷 · 责骂 · 质问
叫（动物/自然）：吠 · 吼 · 嚎 · 啼 · 鸣 · 嘶 · 嗷 · 吟 · 啸

### 手部动作

捏 · 揉 · 搓 · 弹 · 托 · 摊 · 挥 · 戳 · 拽 · 捧 · 拈 · 攥 · 掰 · 掬 · 抚

### 脚步 / 行走

蹦 · 跳 · 跺 · 踢 · 蹭 · 踮 · 滑 · 踩 · 跨 · 跑 · 踱 · 挪 · 蹒跚 · 趔趄

### 面部

皱 · 抿 · 瞪 · 眨 · 撇 · 扬 · 垂 · 咬 · 嘟 · 舔 · 睨 · 蹙

> 技法提示（动作拆解 / 慢镜头）：把一个动作拆成几步，慢慢写。
> 例：「他把鱼翻了个身，用筷子戳了戳，说：『熟了。』」

## 二、量词：中文的隐藏考点

量词是母语者与 AI 最容易露馅的地方。**错一个量词，整句就掉价。**

| 对象 | 量词 |
| --- | --- |
| 月 | 一轮明月 |
| 风 | 一阵清风 |
| 珠 | 一串珍珠 |
| 笑声 | 一片欢声笑语 |
| 烟 | 一缕青烟 |
| 香 | 一炷香 / 一瓣心香 |
| 光 | 一道光 / 一缕光 |
| 舟 | 一叶扁舟 |
| 井 | 一口井 |
| 灯 | 一盏灯 |
| 茶 | 一杯 / 一盏 / 一碗茶 |
| 山 | 一脉 / 一带 / 一座山 |
| 星 | 一点 / 一颗星 |
| 雪 | 一场 / 一片雪 |

## 三、叠词

### ABB（色彩与形态见长）

金灿灿 · 黄澄澄 · 绿莹莹 · 绿油油 · 红彤彤 · 红艳艳 · 红扑扑 · 白茫茫 · 白花花 · 白皑皑 · 白晃晃 · 黑乎乎 · 黑压压 · 黑洞洞 · 黑漆漆 · 黑黝黝 · 胖乎乎 · 圆滚滚 · 亮晶晶 · 湿漉漉 · 冷冰冰 · 暖融融

### AABB

摇摇摆摆 · 恍恍惚惚 · 清清楚楚 · 明明白白 · 干干净净 · 飘飘洒洒 · 高高高兴兴（误）→ 高高兴兴 · 断断续续 · 挨挨挤挤

### ABCC

神采奕奕 · 星光熠熠 · 小心翼翼 · 炊烟袅袅 · 白雪皑皑 · 烈日灼灼 · 赤日炎炎 · 绿浪滚滚 · 果实累累 · 生气勃勃 · 兴致勃勃

### ABAC

载歌载舞 · 蹑手蹑脚 · 若即若离 · 古色古香 · 无影无踪 · 无边无际 · 自言自语 · 时隐时现 · 半明半昧

> **单字叠（最朱自清的一种）**：曲曲折折 · 田田 · 亭亭 · 层层 · 粒粒 · 缕缕 · 脉脉 · 淡淡 · 薄薄 · 静静
> 纪律：**一篇内 2–3 组封顶**。这是 1930 年代散文的做法，当代写作要减量——朱自清可以用「曲曲折折的荷塘上面，弥望的是田田的叶子」，今天照搬就会显旧。

## 四、声音 / 拟声

自然：哗啦啦（雨）· 轰隆隆（雷）· 淅淅沥沥（细雨）· 簌簌（落叶/雪）· 潺潺（溪）
生活：叮铃铃（铃）· 咔嚓（剪/断）· 咕嘟（煮）· 啪嗒（滴水）· 窸窸窣窣（翻动）
动物：叽叽喳喳（鸟）· 汪汪（狗）· 喵喵（猫）· 咩咩（羊）· 呱呱（蛙）

> 技巧：拟声词**一次一个**。连用两个会显得吵。

## 五、古雅颜色词（⚠️ 高风险，默认不用）

> **先读这段再往下看。** 下表这些字在过去几版都是「提升密度」的推荐词，现在改为**默认不用**。
> 原因：它们在现代中文里出现，九成是在制造文艺腔——「绯红的夕阳、黛青的远山、缃黄的稻田」三连串，读起来像中学生摘抄本。
> **只有两种场合可以用**：一是题材本身是古典的（写古画、写文物、写旧体诗）；二是全文已建立统一的文言调门。
> 其余情况，直接写「红」「深红」「天快黑了」。**朴素不丢分，端起来才丢分。**

| 字 | 色 |
| --- | --- |
| 绯 / 绛 / 殷 | 红（绯是浅红、绛是深红、殷是赤黑） |
| 丹 / 朱 / 赭 | 红（丹朱为明红，赭为红褐） |
| 缃 / 鹅黄 | 浅黄 |
| 靛 / 绀 | 深蓝（靛近紫蓝，绀为微红之黑蓝） |
| 缥 / 黛 | 淡青 / 青黑（黛多用于眉与远山） |
| 缁 | 黑 |
| 缟 / 素 | 白 |
| 檀 / 缇 | 浅红 / 橘红 |

**现代替代（推荐）**
| 不要写 | 改写 |
| --- | --- |
| 天色转靛，远山只剩一道黛 | 天快黑了，山只剩一个黑边 |
| 绯红的夕阳 | 太阳压在山口上，红得发烫 |
| 缃黄的稻田 | 稻子黄了 |

> 同类高风险词，一并拉黑：**氤氲、缱绻、旖旎、阑珊、潋滟、葳蕤、岑寂、婆娑、绰约、缥缈。**
> 详细替换表见 `modern-voice.md` 第五节「降调表」。

## 九、意象字表（写景写情的高频核心）

自然：风 · 月 · 云 · 雨 · 雪 · 霜 · 露 · 烟 · 霞 · 山 · 水 · 江 · 湖 · 舟 · 灯 · 窗 · 桥 · 巷
植物：柳 · 荷 · 桂 · 梅 · 竹 · 松 · 蒲 · 苔 · 苇 · 稻 · 麦
时间：晨 · 暮 · 夜 · 秋 · 冬 · 岁 · 流年
身体：影 · 背 · 手 · 声 · 步 · 眉 · 眼

**意象的用法不是罗列，是「一个意象贯穿全文」。** 汪曾祺《昆明的雨》以「雨」为核心意象，串联零散片段；朱自清《背影》以「背影」为支点。**一篇一个核心意象，够了。**

## 九点五、⚠️ 高风险词黑名单（默认不用）

下面这些词不是错词，是**已经被用到失效的词**。写出来读者不会觉得你有文采，只会觉得你在模仿。

| 类别 | 黑名单 | 处理 |
| --- | --- | --- |
| 古雅形容词 | 氤氲 · 缱绻 · 旖旎 · 阑珊 · 潋滟 · 葳蕤 · 岑寂 · 婆娑 · 绰约 · 缥缈 · 馥郁 · 泠泠 | 删。写那个具体的物 |
| 古雅颜色词 | 绯 · 绛 · 缃 · 缥 · 靛 · 黛 · 缁 · 缟 · 檀 · 缇 | 换红/深红/浅黄/淡青/青黑/黑 |
| 文言虚字 | 亦 · 皆 · 乃 · 矣 · 焉 · 哉 · 岂 · 莫不 · 可谓 · 殊为 · 颇为 | 删。现代文不用 |
| 软化比喻词 | 仿若 · 宛如 · 犹如 · 恍若 · 恰似 · 宛若 | 换成「像」，或直接不比喻 |
| 时间副词 | 不禁 · 不由 · 悄然 · 忽而 · 倏然 · 刹那 · 须臾 | 多数直接删，或换「就」「忽然」 |
| 模板句 | 岁月静好 · 时光温柔 · 山河远阔 · 人间清醒 · 万物可期 · 向光而行 · 熠熠生辉 · 温柔以待 | **整句删** |
| 公共意象 | 月光 · 晚风 · 星辰 · 秋雨 · 旧巷 · 灯火 · 山海 · 泛黄的照片 · 微光 | 换成本地本人的具体物象 |

**判别法（比看词表更管用）**：
写完一段，问自己一句——**「这句话，换个人来写会不会一模一样？」**
会，就是黑名单里的东西，删掉重写。

## 十、使用时的一句话总纲

> **具体胜过华丽。**「他很难过」是零信息；「他攥着空口袋，跟着人流往上挤」是全部信息。
> 形容词交代你的判断，动词和名词交代世界。**多给世界，少给判断。**
