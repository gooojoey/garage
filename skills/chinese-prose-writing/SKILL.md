# 汉语文笔写作技能

## Overview

大模型写中文时，底层往往先按英文的逻辑组织句子，再逐句「翻」成汉字。结果就是：语法全对，读起来却像机翻——句子偏长、被动偏多、连接词层层叠加、「的」字连成串、动词被拆成「进行 + 抽象名词」的空壳。这种病在语言学界有名字，叫**欧化中文（恶性西化 / 翻译腔）**，余光中 1987 年就在《明报月刊》系统性批判过。

本技能做三件事：

1. **祛病**——把欧化句式逐类揪出来并给出改法（`references/anti-translation-ese.md`）。
2. **上韵**——用长短句、四字格、对仗、平仄交替重建中文的音乐性（`references/rhythm-and-music.md`）。
3. **提质**——用白描、留白、通感等技法和可查证的文学素材，把「通顺」抬到「好看」（`references/technique-toolkit.md`、`style-models.md`、`lexicon.md`、`literary-sources.md`）。

面向 ChatGPT 等外部工具时，直接用 `references/chatgpt-instructions.md`——那是一份可整段复制粘贴的成品指令。

## When to use

- 用户要写/改中文散文、随笔、书评、影评、评论、品牌文案、朋友圈或公众号文章。
- 用户说 AI 的中文「像翻译腔」「英文味重」「没有人味」「读着不自然」「太像 AI 写的」。
- 要审稿：拿到一段中文（尤其是 AI 生成或英译中的稿子）想让它「更像中文」。
- 要引用古诗文、名句、文学素材，需要靠谱出处而不要二手转引。

## 核心方法：五步走

### 第 1 步 · 定调（只做三件事，别跳过）

先回答三问，答案决定了后面所有的句法选择：

- **谁在说？** 给一个具体的人设，越具体越稳（例：「《三联生活周刊》做了十二年文化报道的主笔」）。
- **对谁说？** 对象越具体，用词越准（中学生 ≠ 行业专家 ≠ 同龄朋友）。
- **什么调子？** 冷静旁观 / 温热第一人称 / 冷峻刻薄 / 清淡冲和。**不要中性**——中性就是 AI 腔的温床。

### 第 2 步 · 立意与结构

- 立意先于文采。问「这篇文章只想说清哪一件事、哪一个感受？」说不清就先别写。
- 选骨架：文学性强用 **起承转合**；要好看好用 **凤头·猪肚·豹尾**；说理性文字用「现象—归因—反例—落点」。
- 详见 `references/technique-toolkit.md`。

### 第 3 步 · 起草（允许粗糙）

用具体的人、事、物、动作把内容撑起来，先不管文采。**这一步最大的忌讳是提前雕琢形容词**——形容词是后来加的，不是打底的。

### 第 4 步 · 祛病（本技能的立身之本）

按 `references/anti-translation-ese.md` 逐类清一遍。优先扫这六样：

| 病灶 | 搜索式 | 改法 |
| --- | --- | --- |
| 万能弱动词 | `进行` `作出` `予以` `加以` `开展` | 还原成实义动词：进行研究→研究 |
| 被动泛滥 | `被` `由` `受到` `得以` `为…所` | 改主动，或用「获」「遭」「挨」「受」 |
| 的的不休 | 一句话里 `的` ≥ 3 个 | 定语改后饰，或删掉 |
| 连词堆砌 | `然而` `因此` `此外` `并且` `以及` `从而` | 删，或断句成两句 |
| 名词化 | `性` `度` `化` 结尾的抽象名词作主语 | 换成具体名词/动作 |
| 前饰长定语 | 中心词前挂一长串修饰 | 挪到名词后面，用逗号隔开 |

句子通顺但「哪儿怪怪的」，就是这一步没做。**机器中文的病在结构，不在词。**

### 第 5 步 · 上韵与定稿

- 长句短句交替排。一句一分句，读得上气不接下气就断。
- 「的」字瘦身，四字格点睛但**不堆砌**（一篇文章三四个足矣）。
- **朗读测试**：出声读一遍，结巴的地方就是要改的地方。
- 结尾不升口号、不总结「综上所述」，学豹尾——短、狠、留余韵。
- 详见 `references/rhythm-and-music.md`。

## 硬规则（违反即返工）

1. **禁止**把原文当英文翻。写中文就用中文的语序想，不先想英文再译。
2. **禁止**「综上所述」「总而言之」「不难看出」「值得一提」「在当今…的时代」这类空转词开头或收尾。
3. **禁止**结尾喊口号（「让我们一起期待」「共同开启新篇章」）。
4. **禁止**为普通名词、比喻词随手加引号；引号只用于真正需要标示的地方。
5. **禁止**排比式对仗成瘾（「不是 A，是 B」「不仅 A，而且 B」连用三次以上）。
6. 引用古诗文名句**必须注明出处**（朝代·作者·篇名），不确定就标注「待核」，不得杜撰。
7. 改稿只改表达，**不增删事实、数字、专有名词**。
