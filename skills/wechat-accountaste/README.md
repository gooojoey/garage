# WeChatAccountaste

让公众号文章读起来舒服，也有自己的样子。

适合已有文稿和图片、希望改善阅读体验的人。它根据内容选择排版方式，整理标题层级、正文节奏和图文关系，输出文字可继续编辑的 HTML。

## 能帮你做什么

- 为一篇新文章建立统一的字号、间距、颜色和图文节奏。
- 调整已有排版中的层级混乱、装饰过多、图片拉伸或手机阅读问题。
- 根据文章类型选择合适的表达，不给所有稿件套同一张模板。
- 交付可编辑 HTML，并说明还需要在哪些环境中检查。

默认只做排版，保留原稿的内容、数字、引语、链接和图片归属；不自行改写文章、增加金句或添加推广语。

## 四种方向，按内容选择

| 方向 | 更适合 |
| --- | --- |
| **文艺阅读** | 随笔、书评、情感与文化观点，重视连贯阅读 |
| **视觉杂志** | 人物、空间、器物和生活方式，让图片参与叙事 |
| **清晰行动** | 方法、知识、步骤和活动信息，方便快速查找重点 |
| **创意主题** | 品牌专题、节日内容，以一个视觉概念贯穿全文 |

不必先懂这些术语。告诉 AI 文章给谁看、希望读起来是什么感觉，就可以开始。

## 你需要提供什么

提供完整文稿、可用图片，以及已有的品牌要求。如果有喜欢的参考文章或截图，也可以一起给出。没有图片时可以做纯文字排版，不会为了填位置加入无关图片。

## 可以这样开始

> 使用 WeChatAccountaste，为下面这篇书评做公众号排版。保留原文和引用，风格安静、清楚，不要增加关注或转发提示。

调整已有排版时：

> 使用 WeChatAccountaste，检查这个 HTML 的标题层级、图片比例和手机阅读效果。保留文字内容，直接修复有问题的部分。

支持命令式调用的工具可使用 `$wechat-accountaste`。

## 你会得到什么

通常是正文 HTML、简短的设计说明，以及尚未解决的素材或验证事项。HTML 中保留可编辑文字和真实图片，不把整篇文章做成一张长图。

交付前应检查窄屏、文字放大和深浅背景。有条件时还会检查微信实际预览与编辑效果；普通浏览器显示正常，不等于微信端已验证。技能不会自动发布文章。

## 设计依据

这套方法从早期文艺、生活方式、知识与品牌公众号的编辑案例中提炼，重点是阅读顺序、图片的作用、栏目一致性和作者归属。

它不是某个账号的官方模板，也不承诺复刻历史版式。字号和间距是可调整的设计起点；默认正文14px，已有品牌要求或大字阅读需求优先。详细案例及证据范围保留在[参考来源](references/source-notes.md)，不影响直接使用。
