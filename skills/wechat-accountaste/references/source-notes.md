# 早期样本与审美提炼依据

整理日期：2026-09-08。优先2015—2017年材料；无法获得足够早期内容时明确标注补充年份。本文只保存链接与原创分析，不收录第三方整篇文章、插画、截图、标识或二维码。

## 阅读边界

- **历史内容转存**：读到了标明账号来源的文章结构或全文。能判断章节、问答、署名和图文顺序；不能证明转存平台保留了微信原始CSS。
- **历史版式图片**：实际查看到历史资料内的图片，只证明这张图片的设计，不能推断整篇或账号全部时期。
- **二手分析/检索片段**：用于补充和定位，不冒称读过原生微信全文。

本次未完成十个账号的原生微信页面视觉核验。部分原文和转存页面受访问限制，浏览器也出现超时。因此不提供“各号实测字号、行距、色号”，不把设计建议包装成品牌官方规范。

## 综合方法如何落地

1. 取阅读秩序、图片任务、栏目稳定性、作者归属和形式一致性作为共用标准。
2. 允许文艺阅读、视觉杂志、清晰行动、创意主题四种表达，按内容选择，不平均混合。
3. 数值由可读性和平台兼容性重新制定；历史小字、低对比灰、图片承载正文、复杂SVG等做法不自动继承。
4. 若未来用户要求“严格复刻某篇”，先获得那篇的原文或截图，重新测量和核验；这份综合Skill不能替代具体样本证据。
