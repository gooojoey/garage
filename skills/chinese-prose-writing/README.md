# ChineseProseWriting · 汉语文笔写作

给 AI 的中文写作教练。解决的问题很具体：**AI 写的中文，读起来像英文机翻。**

语法全对，句子通顺，但读第二遍开始觉得「哪儿怪怪的」——这就是翻译腔（欧化中文）。这个技能把它拆成可诊断、可修改的六类病灶，再补上中文的节奏、技法和素材。

## 适合谁用

- 你让 ChatGPT 写中文，出来的东西一股「翻译腔」「英文味」。
- 你要写散文、随笔、书评、评论、品牌文案，希望读起来像人写的。
- 你手里有一段 AI 稿或英译中的稿，想让它「更像中文」。
- 你要引古诗文名句，需要靠谱出处。

## 它做什么

### 一、祛病

六类病灶，每一类都给了搜索式、改法和真实对照：

| 病灶 | 长什么样 | 怎么改 |
| --- | --- | --- |
| 万能弱动词 | 「对这个问题进行深入的探讨」 | 深入探讨这个问题 |
| 被动泛滥 | 「他被升为营长」 | 他升为营长 |
| 的的不休 | 一句话三个「的」 | 定语挪后，或删 |
| 连词堆砌 | 然而、因此、此外、并且、以及 | 删一半，不通就断句 |
| 抽象名词 | 「用户留存率有显著提升」 | 回头再来的人变多了 |
| 前饰长定语 | 「一个长得像你兄弟的男人」 | 一个男人，长得像你兄弟 |

配套一个自检脚本，自动把这些标出来。

### 二、上韵

中文的节奏不在词上，在长短句的搭配上。技能里给了可操作的节律规则：长短句交替、四字格用量上限、叠词配额、平仄的入门用法、「的」字瘦身四招，以及最有效的免费工具——朗读测试。

### 三、提质

结构用「凤头·猪肚·豹尾」和「起承转合」两套中国文章学的骨架；技法收白描、列锦、通感、留白、情绪藏细节、小波折六种；范本拆解汪曾祺、沈从文、张爱玲、朱自清、老舍、鲁迅六家的风格与可模仿句式。

## 怎么用

### 给 ChatGPT 用（最直接）

打开 `references/chatgpt-instructions.md`，里面有四段可以直接整段复制的成品指令：

- **完整版**——贴到 ChatGPT 项目的 Instructions，或自建 GPT 的 Instructions。
- **精简版**（约 1300 字）——贴到「设置 → 个性化 → 自定义指令」，长期生效。
- **改写指令**——手里已有 AI 稿时，单次对话直接发。
- **写作模板**——从零写一篇时用。

推荐组合：精简版放自定义指令长期兜底，写作时再补发一次写作模板。

### 给支持 Skill 的工具用

安装本技能后，直接提需求即可：

> 用 ChineseProseWriting 帮我改这篇文章，去掉翻译腔。
>
> 用 ChineseProseWriting 写一篇 1200 字的散文，主题是「成都的雨」。先跟我确认人设和调子。

### 单独跑自检脚本

```bash
python scripts/clinic.py 稿子.txt
python scripts/clinic.py 稿子.txt --json
```

输出每一处病灶的行号、命中片段和改法，末尾附体检数据（平均句长、「的」密度、长短句是否单调）。

## 用之前知道这几件事

- **这不是「一键变文豪」。** 它给的是诊断标准和改写规则，最终判断仍要人来做。工具能让你稳定避开 AI 腔的下限，上限靠你自己读了多少书。
- **禁用词是概率规则，不是绝对禁令。** 「进行」在「进行曲」里没错，「的」在需要的时候该用。脚本命中不等于错，需人工判断。
- **名句出处请复核。** `literary-sources.md` 中的名句多为通行版本，部分来自聚合类文章的二手汇总，已在文末标注。正式发表、教学或商用前，请用[古诗文网](https://www.gushiwen.cn/)或纸质权威版本核对作者与篇名。
- **改稿只改表达。** 事实、数字、专有名词一个都不动。

## 依据

技能里的每一条规则都有出处，主要来自：

- 余光中《怎样改进英式中文？——论中文的常态与变态》，原载《明报月刊》1987 年 10 月号
- 王力《略论语言形式美》《诗词格律》
- 汪曾祺《小说笔谈》（原载《写作》1991 年第 4 期）及论语言系列
- 夏丏尊、叶圣陶《文心》（1933）
- 元·乔吉「凤头·猪肚·豹尾」（载陶宗仪《南村辍耕录》）；清·刘熙载《艺概·经义概》「起承转合」

每份 reference 文件末尾都列有完整出处表。使用前建议先读 `anti-translation-ese.md` 的第二节速查表——只有半页，但能立刻用起来。
