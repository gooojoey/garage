# WeChatStickers

从一个角色，做出一整套微信表情。

适合想把自己、家人、朋友或品牌吉祥物做成表情包的人。它把角色设计、动作设计、透明 GIF 导出和专辑物料整理成一条工作流程，也可以只做其中一步。

[下载 WeChatStickers.skill](https://github.com/gooojoey/garage/raw/refs/heads/main/WeChatStickers.skill) · [返回 Garage](https://github.com/gooojoey/garage)

## 它会怎么做

1. **先定形象。** 询问你喜欢的画风，根据参考图设计角色，等你确认后再继续。
2. **再做表情。** 根据表情清单设计动作、服装和小道具，检查动作衔接、角色一致性和循环节奏。
3. **补齐专辑物料。** 制作横幅、封面、聊天页图标；需要时再做头像和赞赏图片。
4. **整理交付。** 分类保存 GIF、缩略图、物料、预览和制作源文件，并检查规格。

已经有满意的角色？可以直接沿用。只想改几款表情或补一张横幅？也不需要从头开始。

## 你需要提供什么

- **参考素材：** 人物照片、角色图，或一段清楚的形象描述。
- **偏好：** 想要的画风、性格、服装，以及希望保留的识别点。
- **表情清单：** 例如你好、早安、晚安、比心、忙、开心；没有想好时，可以先让 AI 提建议。
- **用途和位置：** 是否准备提交微信、是否需要专辑物料，以及文件保存在哪里。

## 可以这样开始

> 使用 WeChatStickers，为这个人物设计16款微信动态表情。风格简约、亲切，保留眼镜和发型。先设计形象给我确认，再制作表情和专辑物料。

已有形象时：

> 使用 WeChatStickers，沿用这张已确认的角色图，只制作横幅、封面和聊天图标。

修改动作时：

> 使用 WeChatStickers，检查这套 GIF 的动作衔接和裁切位置。保留人物设计，修复跳动、道具变化和背景残留，另存为新版。

支持命令式调用的工具可使用 `$wechat-stickers`。

## 默认交付规格

| 内容 | 默认规格 |
| --- | --- |
| 动态表情 | 240×240 GIF，透明背景、循环播放，同辑8–24款 |
| 对应缩略图 | 240×240 PNG |
| 详情页横幅 | 750×400 JPG/PNG，不透明背景 |
| 专辑封面 | 240×240透明 PNG，半身或全身 |
| 聊天页图标 | 50×50透明 PNG，以头部为主 |

默认尽量控制每个文件在500KB以内，聊天图标在100KB以内。以上来自制作流程中收集的提交要求，并非实时官方规范；提交前请以微信后台为准。更多参数见[规格说明](references/specifications.md)。

## 它特别关注什么

动作要明显，也要连贯；同一个角色不能每帧变脸、换颜色或忽大忽小。手机、麻将、食物等道具要有合理的朝向与动作。透明背景要检查实际透明通道，不能只看画面像不像棋盘格。

这些检查需要看最终图像和循环播放。脚本可以检查格式、尺寸和体积，不能代替视觉判断。

## 运行条件

需要支持 Skill 的 AI 工具，并具备图像生成、编辑及文件处理能力。技能包本身不含绘图模型；工具能力不足时会说明限制。安装方式见[仓库首页](https://github.com/gooojoey/garage#怎么使用)。

随附的 Python 脚本用于**已经生成、抠好的素材**的对齐、导出和打包，需要 Python 3.10+ 与 Pillow。它不负责画图或自动抠图。只使用工作流指令时，不必预先安装这些脚本依赖。
