# 参数与范围

以下是用户在工作流提供的参数，记录于 2026-09-08；**不是实时核验的微信官方规范**。最新后台/用户截图优先。需要确认现行要求时查官方渠道，无法验证就说明，不把旧参数称为最新规则。

| 文件 | 默认格式/尺寸 | 体积目标 | 背景与内容 |
|---|---|---|---|
| 动态专辑表情 | GIF 240×240，8–24 张 | ≤500,000 字节/张 | 真透明、无限循环，整辑统一动态 |
| 静态缩略图 | PNG 240×240 | ≤500,000 字节 | 与 GIF 对应，选代表帧 |
| 详情页横幅 | JPG/PNG 750×400，1 张 | ≤500,000 字节 | 不透明、非白底、明快有故事，默认无字 |
| 专辑封面 | PNG 240×240，1 张 | ≤500,000 字节 | 真透明、正面半身/全身、少留白、无白描边无字 |
| 聊天页图标 | PNG 50×50，1 张 | ≤100,000 字节 | 真透明、仅头部、无白描边方框文字，实际尺寸清楚 |
| 微信头像（可选） | PNG 240×240 | ≤500,000 字节 | 按用户需要选择背景，非聊天图标 |
| 赞赏引导（可选） | JPG/PNG/GIF 750×560 | ≤500,000 字节 | 与角色一致，鼓励支持，不强迫或承诺利益 |
| 赞赏致谢（可选） | JPG/PNG/GIF 750×750 | ≤500,000 字节 | 与角色一致，表达谢意 |

500KB/100KB 是用户描述的压缩阈值，本流程用更保守的十进制目标，不把超限误称为必然拒审。若用户明确选静态专辑，可统一 PNG/JPG/GIF 240×240；动态不顺利不能擅自降级。

名称默认≤8字符，简介≤80字符（保守含标点计数）。不编造审核通过、疗效、贷款结果或背书。构图可使主体及字幕合计占85%–95%、留少量安全边距；这是设计建议非平台硬性规则。GIF只有二值透明，不能完整保留PNG半透明柔边；合理阈值、共享调色板及深浅底检查减轻锯齿，不加白边掩盖问题。
